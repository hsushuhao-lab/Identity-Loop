# 一、全域規則修改

原本：

`M1 → M2 → M3 → M4 → M5 → M6 → M7 → M8 → M9`

不再代表所有角色的固定時間順序。

今後：

- `M1` = 3F / 316 交班事件模組
- `M2` = 4F 查房 / 409-A
- `M3` = 急診 / 00:33 / legacy record
- `M4` = 第二院區 504B

- `M6` = Phantom 6F
- `M7` = 02:17 / B-Panel / B2
- `M8` = Identity Rejection
- `M9` = 316 Final Handover

四名角色按照各自人格，使用不同順序進入這些模組。

但所有路線最後固定收斂：

**M6 → M7 → B2 → M8 → M9**
