## 最後交班規則

四條路線在 M9／316 的綠字舊終端都使用兩組獨立選項：姓名四選一、員編四選一。沒有自由輸入欄、預設答案或自動配對。兩組顯示順序不同，不能按相同行位置推算配對。

兩項都選完後才能按「正式提交交班（不可更改）」。送出前可以更改選項，但不能提前得到正誤回饋。正式提交後先同步保存兩個選擇與回合結束狀態，再播放對應結局。

成功條件是姓名與員編都屬於本輪身分，不只是兩者互相對得上。姓名對但員編錯、姓名錯但員編對、都錯，或選到別條路線的完整正確配對，一律為 WRONG MEMORY Bad End。缺一項不會提交，也不消耗機會。有效選項提交只有一次；重複點擊及重新整理不能改判或重選。

M9 提示及通往最後交班的文案同步改成「選擇／選定姓名與員編」。不更動其他密碼鎖的輸入方式。

## 四個不同的通關動畫

每條 Good End 為 24 秒、3 個鏡頭的即時 Three.js 演出，不是同一張圖換標題。使用現有 GLB 家具、材質與各自的證物配置；相機移動、道具動作、字幕及合成尾奏分開定義。

| 路線 | 結局 | 演出 |
| --- | --- | --- |
| LI | THE ORDER | 保留原始紀錄，在旁另附更正；紅筆停住，錯誤不再被擦除。 |
| ZHANG | THE NAME | 床邊記錄分列親見、轉述與待核事項；門逐漸開啟，責任交給下一班。 |
| ZHOU | THE WARNING | 相機放下，未送達便條移向接收盤；讓警告離開桌角。 |
| CHEN | THE TRANSFER | 輪椅停在門前，撤銷錯誤目的地，將接收責任重新核對。 |

動畫提供暫停、繼續及略過；結束後可從已保存的結局面板重看。新動畫模組延後至 Good End 才載入，不增加新的二進位素材檔。載入失敗不清除或重開交班結果，可返回結局面板重試播放。錯誤交班沿用既有病人化結局，這一版沒有宣稱另做四套 Bad End CG。

前一輪截圖發現的紙張超出桌面、物件缺乏桌面支撐及窄畫面輪椅裁切，已在候選版本修正並重驗。自動播放測試與暫停截圖分开：第一次自然播放完整 24 秒並讀取真實渲染幀；截圖另用重播暫停取得，不以截圖耗時影響自然播放斷言。

## 測試邊界與重跑

測試使用固定 M9 存檔檢查點，到物理可站立且視線未被遮擋的位置對終端按 E，之後使用實際選項與提交按鈕。主世界渲染採按需取樣，結局渲染與 24 秒時鐘自然執行；不是從開場到 M9 的四線全程走查。390px 檢查不等於手機實機觸控或所有顯示晶片認證。仍有既有大型 bundle 警告，這次不宣稱載入效能已改善。

在 `prototype` 下執行：

```sh
npm ci
npm run test:identity
npm run build
npx playwright install --with-deps chromium
node scripts/test-identity-m9-pair-browser.mjs qa-results/m9/browser
```

正式站重驗可將已部署的入口作為第三個參數傳給同一腳本，並在測試前後使用 `scripts/verify-live-build.mjs` 核對 SHA。測試檢查點與成就只寫入新建的自動化瀏覽器環境，不修改使用者既有存檔。
