# Identy Loop Version 2 master spec

## Scope

`Identy Loop` is an independent production game derived from the current `DutyNight/master` runtime. `DutyNight` remains the straight-line Version 1 project and is not modified by this repository.

The physical route is one shared hospital route from M1 through M9. A hidden identity seed changes perception, memory, and the final inference; it does not create four duplicated games.

## Identity contract

The four identities are `ZHANG`, `LI`, `ZHOU`, and `CHEN`. A new run draws exactly once and persists that draw in the `IdentyLoop_IdentityState_v1` namespace. Reloading an unfinished run never draws again. A bad end does not complete an identity. Four good ends unlock M10 for the next new run.

## Route contract

`M1 3F → M2 4F/409-A → M3 21:17/ER/316 → M4 second campus 504B → M5 surveillance/skybridge → M6 phantom 6F → M7 02:17/B-panel → B2 one-way archive → M8 rejection → M9 final handover`.

M5 is skybridge-only. B2 is irreversible after entry. M9 exposes four candidate files and has one irreversible submit action.

## Claim boundary

M1–M8 use procedural familiarity, sensorimotor memory, and contradiction. They never state the current identity. Names are player-facing only in B2’s objective archive and the M9 choice list; the current identity is not auto-solved.
